# GradeGravity ⚡
### LNMIIT SGPA Calculator — All Branches, All Semesters

> **Live Site → [gradegravity-lnmiit.vercel.app](https://gradegravity-lnmiit.vercel.app/)**

Built for every LNMIIT student tired of calculating SGPA manually. Select your branch, select your semester, enter your grades — done.

---

## What is this?

GradeGravity is a free, fast, no-login SGPA calculator built specifically for **The LNM Institute of Information Technology, Jaipur** — covering the **Y23 curriculum** for all branches.

## Features

- All 6 active branches with complete semester-wise course and credit data
- Auto-populated courses and credits — no manual entry needed
- S/F graded courses (Indian Knowledge System, Environmental Science, Disaster Management) handled automatically — excluded from SGPA calculation with a simple S/F toggle
- SGPA formula: `Σ(Credits × Grade Points) / Σ(Credits)`
- Standard LNMIIT 10-point grading scale: A=10, AB=9, B=8, BC=7, C=6, CD=5, D=4, F=0
- Animated SGPA result with performance status
- Full breakdown table: Course | Credits | Grade | Grade Points | Weighted Score
- Semester 8 flexible input for Industrial SLI / Thesis / Electives options
